## What the hardened runtime is

Every NanoClaw agent runs inside an isolated sandbox. The **Echo hardened runtime** is a locked-down version of that sandbox, secured all the way down to the software it runs on. Through the NanoClaw and Echo partnership, NanoClaw is the first open-source agent framework to offer its community a hardened agent environment. Echo rebuilds the software inside the agent environment from scratch, including only the essential components, which cuts the count of known vulnerabilities from thousands down to near zero. Echo hosts and maintains this environment as a single source of truth and keeps it patched over time. Echo's own agents research newly disclosed vulnerabilities, build fixes, run compatibility testing, and open pull requests for human review before anything ships. Only these components are baked into the hardened runtime:

- Chromium browser
- node
- bun
- pnpm
- corepack
- git
- curl
- unzip Nothing else is included.

## Why you would want it

- **Smaller attack surface.** Stripping the environment down to essential components takes the known-vulnerability count from thousands to near zero.
- **Maintained for you.** Echo keeps the runtime patched as a single source of truth, so you are not tracking and rebuilding it yourself.
- **Zero cost.** The hardened runtime is free.
- **Fully optional.** If you prefer to build and manage your own local runtime, that path stays fully supported.

<Warning>
  The hardened runtime greatly reduces exposure to known vulnerabilities. It is not a guarantee against all risk, and no environment is fully immune from attack. Run it as one layer of a broader security posture.
</Warning>

## Troubleshooting and FAQ

<AccordionGroup>
  <Accordion title="Is the hardened runtime really free?">
    Yes. The hardened runtime is free and opt-in. There is no paid tier to unlock it.
  </Accordion>

  <Accordion title="Do I have to use it?">
    No. The DIY local runtime stays fully supported. The hardened runtime is an additional option, not a requirement, and existing installs are not changed unless you opt in.
  </Accordion>

  <Accordion title="Does this make my agents impossible to attack?">
    No. The hardened runtime reduces exposure to known vulnerabilities to near zero by stripping the environment down to essential components. It does not remove all risk, and no environment is fully immune from attack.
  </Accordion>

  <Accordion title="What software is included?">
    Chromium browser, node, bun, pnpm, corepack, git, curl, and unzip. Nothing else is baked in.
  </Accordion>

  <Accordion title="Who keeps it patched?">
    Echo maintains the runtime as a single source of truth. Echo's agents research new vulnerabilities, build fixes, run compatibility testing, and open pull requests for human review before changes ship.
